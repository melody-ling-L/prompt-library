# Few-shot 选例三原则

> 2026-04-21 · 从中文讽刺识别实验中沉淀

## 三原则

### 1. 代表性（Representativeness）
例子要覆盖真实输入的分布，不能只选"教科书好例子"。

### 2. 多样性（Diversity）
每个类别都要有例子，不能集中在一类。

### 3. 边界性（Boundary）
必须包含刁钻/模糊的边界案例，让模型学决策边界。

## 实验数据支撑

| Prompt 版本 | 违反原则 | 准确率 |
|---|---|---|
| 好 Few-shot | 无 | 100% |
| 坏1（全正面） | 多样性 | 80% |
| 坏2（全极端） | 边界性 | 90% |
| 坏3（太简短） | 代表性 | 90% |

## 口诀

每条例子问自己3个问题：
1. 真实场景会出现吗？
2. 类别和其他例子不一样吗？
3. 让模型学到微妙边界吗？

全是 → 保留；任意不是 → 换。
