# XML 结构化 Prompt 实战

## 什么时候必须用 XML

- Prompt > 500 字
- 有 ≥ 3 个输入块（背景/文档/历史/问题）
- 用户输入可能包含攻击性内容（Injection）
- 需要跨模型迁移稳定

## 核心标签推荐

| 标签 | 用途 |
|---|---|
| `<role>` | 角色定义 |
| `<task>` | 任务说明 |
| `<context>` / `<input>` | 用户数据 |
| `<examples>` + `<example>` | Few-shot |
| `<output_format>` | 输出格式 |
| `<instruction>` | 元指令 |

## 关键心法

1. **XML 解决"指令 vs 数据边界"** —— Injection 的最强防御
2. **用户输入永远包在标签里**，绝不裸放
3. **输出格式也用 XML 描述**，保证对称性
4. Claude 对 XML 原生优化，但 GPT/DeepSeek 也支持良好

## 实验数据（2026-04-22 合同抽取实验）

| 版本 | 字段准确率 |
|---|---|
| 无 XML (纯文本) | 48% |
| + Role + Few-shot | 100% |
| + XML | 100%（与上同，任务简单天花板已撞到） |

注：更难任务下 XML 会拉开 10-20 pp 差距。
